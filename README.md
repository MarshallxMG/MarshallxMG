# 🧑‍💻 About Me

<img align="right" alt="coding" width="380" src="https://cdn.dribbble.com/users/1162077/screenshots/3848914/programmer.gif" />

I'm a **Junior Data Engineer** who loves building **scalable data pipelines**, **automation tools**, and **data-driven dashboards**. I enjoy working across the full data lifecycle — from ingestion and transformation to validation and reporting — and I'm passionate about experimenting with new technologies and turning ideas into real, functional tools.

- 🏢 Currently working as a **Data Engineer**, building **ETL/ELT pipelines** on **Databricks** & **Azure Data Factory**
- 🔎 Specializing in **SQL validation**, **data quality**, and **financial reconciliation** workflows
- 🤖 Exploring **AI-driven testing** & **agentic AI prototypes** to automate QA processes
- 🖥️ Developer of a full **SQL Editor Desktop App**
- 🎵 Created a GUI-based **Music Player**

- 📊 Developed a **Blinkit Dashboard (Power BI)**
- 🌱 Currently deepening my skills in **PySpark, Delta Lake & Cloud Data Engineering**
- 💡 Curious mind, always exploring new tech
